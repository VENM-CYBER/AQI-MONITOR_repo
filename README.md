## Installation

### Clone Repository

```bash
git clone https://github.com/VENM-CYBER/AQI-MONITOR_repo
cd AQI-MONITOR_repo
```

### Backend Setup

```bash
cd backend
pip install -r requirements.txt
python app.py
```

### Frontend Setup

```bash
cd frontend
npm install
npm start
```
